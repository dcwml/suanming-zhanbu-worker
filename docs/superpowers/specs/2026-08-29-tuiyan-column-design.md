# 时辰推演（tuiyan）栏目设计文档

- 日期：2026-08-29
- 状态：已批准，待实施
- 需求来源：用户提议——从农历七月（2026-08-13 ～ 2026-09-10）起，每月推演一篇「特殊时辰」榜单：扫描该农历月每天×12时辰的四柱，专写全阳、贵人、灾星等命格特殊的时辰，配古代国师批语风格（「三天后南方将有贵人出生」式叙事）

---

## 1. 概述

新增第四个纯静态内容栏目「时辰推演」，与 daily / weekly / monthly 并列，**每个农历月发布一篇**。核心原则与既有栏目一致：历法数据全部来自 lunar-javascript，格局识别规则在生成期沉淀为可复用核心（`src/tuiyan/scan.ts`，有单测），文案烘焙进仓库内 HTML 片段，Worker 运行时零 LLM、零历法计算。

内容形态为**精选榜单**（非全量矩阵）：只详写命格稀缺的时辰，常规亮点以速查表带过。

## 2. 决策记录

| # | 问题 | 结论 |
|---|------|------|
| 1 | 收录范围 | 精选榜单：一级大格详写、二级魁罡专节、三级每日亮点速查表；纯阳（本月 78 个、占 22%）只在速查表标注，不单独成条 |
| 2 | 叙事风格 | 仿古批语一句（含方位元素）+ 白话解析两三句；文末免责段声明批语为传统命理文化的趣味演绎 |
| 3 | 页面形态 | 新开系列栏目（曾考虑塞进月运，因农历七月跨公历两月 slug 语义冲突、月运三段式结构不匹配而否决；曾考虑 registry 固定页，因每月持续产出而否决） |
| 4 | 单篇 URL 键 | **农历月首日的公历日期**（如农历七月 → `tuiyan/2026-08-13/`，2026-08-13 为七月初一）。闰月天然无歧义（闰月首日也有唯一公历日期），与 weekly 用周一日期同一哲学 |
| 5 | 路由词 | `tuiyan`（推演）——「推演天机」味浓，与国师批语风格契合（用户在 shichen / yansuan / tuiyan 中选定） |
| 6 | 聚合模块是否并入 registry | **不并入**（与 daily/weekly/monthly 相同取舍）：`src/pages/tuiyan.ts` 维护 `TUIYAN_POSTS` |

## 3. URL 与 SEO 方案

| 页面 | URL | head | JSON-LD |
|---|---|---|---|
| 归档 | `/:lang/tuiyan/` | `buildTuiyanArchiveHead` | CollectionPage |
| 单篇 | `/:lang/tuiyan/YYYY-MM-DD/`（日期 = 农历月首日） | `buildTuiyanPostHead` | Article（datePublished = 该日期） |

- 无尾斜杠 301 补斜杠；路由 4 条，注册在 `/:lang/:slug` 之前；日期校验 `^\d{4}-\d{2}-\d{2}$`
- head 走 `buildStandardHead` 共享助手；sitemap 增加归档与单篇（双语 alternates，与 weekly/monthly 相同模式）
- 导航：「运势」下拉 `FORTUNE_NAV_ITEMS` 加「时辰推演」；footer 运势列同步
- 正文片段自带 `<h1>`（与 weekly/monthly 一致）

## 4. 格局识别规则（scan 核心）

输入农历月首日，自动圈定该农历月（至下一农历月首日前一天），每天 12 时辰以**时辰中点**（0/2/…/22 点，子时取 0 点早子时）排四柱，按规则表打标记：

| 标记 | 规则 |
|---|---|
| 纯阳 / 纯阴 | 四干四支全阳 / 全阴（干支都计） |
| 天乙贵人时 | 日干起贵人落时支（甲戊庚→丑未、乙己→子申、丙丁→亥酉、壬癸→卯巳、辛→午寅） |
| 羊刃时 | 阳日干刃落时支（甲→卯、丙戊→午、庚→酉、壬→子；阴干不论） |
| 桃花 / 驿马 / 将星 / 华盖时 | 日支三合局起，落时支（申子辰→酉/寅/子/辰，寅午戌→卯/申/午/戌，巳酉丑→午/亥/酉/丑，亥卯未→子/巳/卯/未） |
| 魁罡日 | 日柱 ∈ 庚辰、庚戌、壬辰、戊戌 |
| 三合成局 | 四支凑齐申子辰 / 寅午戌 / 巳酉丑 / 亥卯未 |
| 三合方会 | 四支凑齐申酉戌 / 亥子丑 / 寅卯辰 / 巳午未 |
| 日时干五合 / 支六合 | 日柱与时柱天干五合 / 地支六合 |

**分级输出**：

- **一级·大格（grand）**：三合成局 ∨ 三合方会 ∨ 标记总数 ≥ 4（标记含上表全部条目，纯阳、魁罡日等一并计数）→ 逐条详写
- **二级·魁罡（kuigang）**：魁罡日全天时辰列表；已入一级者重点渲染
- **三级·每日亮点（daily）**：一天一行——日柱干支、贵人时、桃花/驿马/将星/羊刃/华盖时支、纯阳日标注（日柱纯阳则该日 6 个阳时辰为纯阳八字）

月柱逐时辰实算，节气换月柱（如白露丙申→丁酉）天然正确；每月总览需说明月柱分段。

## 6. 单篇内容结构

| section class | 内容 |
|---|---|
| `tuiyan-summary` | 农历月界定（含总时辰数）、月柱分段与节气、本月榜单统计、知识点（如丙午年纯阴为零的结构性原因） |
| `tuiyan-grand` | 一级约 20 条：公历日期+农历日+时辰+四柱 → 仿古批语一句（含方位元素）→ 白话解析两三句 |
| `tuiyan-kuigang` | 二级：魁罡日全天简表 + 特殊时辰重点渲染 |
| `tuiyan-daily` | 三级：每日亮点速查表（29 行） |
| 免责段 | 批语为传统命理文化的趣味演绎，仅供参考（页脚既有免责双重覆盖） |

批语文风示例：

> 9月3日（七月廿二）酉时 · 丙午 丙申 庚辰 乙酉
> 批语：「魁罡坐日，羊刃桃花并见，乙庚干合、辰酉支融——刚烈与柔媚同体，将才亦是情种，宜西地。」
> 白话：庚辰日柱为四大魁罡之一……羊刃、桃花、天干五合、地支六合四种标记在同一个时辰汇聚，为全月仅见。

双语对称：英文版用同结构英文演绎（imperial astrologer 口吻），干支保留拼音/汉字并注。首篇发布时农历七月已过半，文案口径为「全月推演总录，已过时辰供回看印证」。文案红线照守（无「AI」字样）。

## 7. 生成器 CLI 与代码落点

```powershell
npm run tuiyan -- 2026-08-13   # 参数 = 农历月首日；输出该月分级榜单 JSON
```

| 模块 | 文件 |
|---|---|
| 格局规则 + 分级 | `src/tuiyan/scan.ts`（进 tsconfig、有单测；CLI 与未来可能的 API 共用） |
| 生成期 CLI | `scripts/tuiyan.ts`（薄壳：参数解析 + JSON 输出） |
| 聚合模块 | `src/pages/tuiyan.ts`（`TUIYAN_POSTS` / `TUIYAN_ARCHIVE_META` / `findTuiyanPost` / `tuiyanArchive`） |
| 正文片段 | `src/content/tuiyan/YYYY-MM-DD.{zh,en}.html` |
| 路由 | `src/routes/pages.ts`（4 条，注册在 `/:lang/:slug` 之前） |
| 渲染 | `src/layout/render.ts`：`renderTuiyanPost` / `renderTuiyanArchive` |
| head | `src/seo/meta.ts`：2 个 builder（走 `buildStandardHead`） |
| JSON-LD | `src/seo/jsonld.ts`：`tuiyanArticleJsonLd`（Article 模式复用） |
| 导航/页脚 | `src/layout/nav.ts`（FORTUNE_NAV_ITEMS 加项）、`src/layout/footer.ts` |
| 样式 | `public/assets/style.css`：`.tuiyan-*` |

每月产出流程：跑 CLI 得骨架 → 手写批语 → 注册 `TUIYAN_POSTS` → `npm test && npm run typecheck`。

## 9. 已知取舍

- 时辰取中点排盘、子时取 0 点（早子时）；晚子时流派差异不展开，工具口径写死
- 纯阳不单独入一级（本月占 22% 不稀缺）；若未来某农历月纯阳稀缺（如阴年阴月），分级规则不变、数量自然减少
- 批语含方位元素属文化演绎，不做「真预言」暗示；免责段必配
- 不做交互工具页、不做全量 348 时辰矩阵（用户已确认精选榜单）
- 首篇之后每月发布；首篇覆盖已过时辰的部分供回看印证，不回溯补写
