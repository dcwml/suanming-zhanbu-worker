# 未来工具候选清单

- 日期：2026-08-17
- 状态：候选规划（未实施），用户将逐一立项实现
- 需求来源：站点已上线算八字、六爻起卦、择吉日三个工具，盘点可扩展的工具方向
- 立项方式：每个工具实施前按惯例单独写设计文档（`specs/YYYY-MM-DD-<工具>-design.md`），本文只做候选盘点与优先级建议，不含实施细节

---

## 1. 概述

现有三个工具覆盖了术数的三大类：**命理（八字）、占卜（六爻）、择日（择吉）**。

架构上，「validate 校验 + prompt 提示词 + types 共享类型 + 路由 + 前端 JS」这套模块模式已被三个工具验证，复制边际成本低：

- **需要解读的工具**（占卜/命理类）：沿用 LLM 解读管线（`callLlm` + RateLimiter + 统一错误码），前端排盘 + 后端解读。
- **纯算法/静态的工具**（抽签、查表、词典类）：零 LLM 成本，可做成静态页面或纯前端工具，与每日/每周/每月栏目同源思路。

下文按类别盘点候选工具，每项标注价值定位与实现体量，供逐一立项时参考。

## 2. 候选工具盘点

### 2.1 占卜类（六爻的同族）

| 工具 | 定位 | 体量 | 备注 |
|---|---|---|---|
| 梅花易数 | 按时间/数字/文字起卦的快卦，与六爻「重卦」互补 | 中 | 起卦逻辑简单，解读可直接复用现有 LLM 管线；是 LLM 模式复制得最顺的一个 |
| 小六壬 | 掐指一算式速占，移动端随手用的轻量入口 | 小 | 算法极轻（月日时起课），纯前端即可完成，可选配 LLM 解读 |
| 奇门遁甲 | 三式之一，分量重、受众专业 | 大 | 排盘复杂，JS 生态现成库少，属高投入选项，建议靠后 |
| 大六壬 | 三式之一 | 大 | 同上，排盘复杂度甚至更高 |

### 2.2 命理类（八字的同族）

| 工具 | 定位 | 体量 | 备注 |
|---|---|---|---|
| 紫微斗数 | 热度与八字并列的头部命理术数，最重磅的候选 | 大 | 排盘可用现成的 iztro 库，解读复用 LLM 管线；做出来即是站点第二个旗舰工具 |
| 称骨算命 | 袁天罡称骨，按生辰算骨重配断语 | 小 | 算法极简单，纯静态即可，适合做轻量引流页 |
| 八字合婚 | 双人八字配对测算 | 中 | 本质是八字模块的延伸（双人排盘 + 配对规则），边际成本低 |

### 2.3 抽签民俗类（性价比最高的流量入口）

| 工具 | 定位 | 体量 | 备注 |
|---|---|---|---|
| 黄大仙灵签 | 抽签类头部流量，纯静态 | 小 | 与站点品牌天然契合——周运评分规则本就是拿黄大仙祠排名回测校准的；签文 + 随机抽取 + 可选 LLM 解签 |
| 观音灵签 | 抽签类搜索量最大的品类之一 | 小 | 同上，纯静态内容，零 LLM 成本（解签可选配） |
| 月老灵签 / 关帝灵签等 | 细分主题签（姻缘/事业） | 小 | 可在抽签框架搭好后低成本扩品类 |

抽签类的共性：**搜索量大、纯静态内容、不花 LLM 成本**。建议先做一个抽签的通用结构（签文数据 + 抽取交互 + 解签展示），再横向复制其他签种。

## 3. 优先级建议

**第一批（快赢，体量小、见效快）**

1. 抽签类（黄大仙灵签 / 观音灵签）——流量大、零 LLM 成本、与站点品牌契合
2. 生肖配对——查表现成的，几乎零开发
3. 黄历任意日期查询——现有历法能力变现

**第二批（中坚，LLM 管线复制）**

4. 梅花易数——复用解读管线最顺
5. 八字合婚——八字模块自然延伸
6. 称骨算命——轻量引流

**第三批（旗舰与长线）**

7. 紫微斗数——第二个旗舰工具，值得单独立项认真做
8. 小六壬、九宫飞星、解梦大全、星座/生命灵数等按流量与精力酌情安排
9. 奇门遁甲、大六壬——高投入，暂缓

以上排序只是建议，实际立项顺序可按兴趣与内容准备情况调整。
